# PIT Liquid Glass refined v4

- **기준**: v3에서 확정된 글자별 경로 및 transform 행렬을 그대로 유지했습니다.
- **개선**: 글자 내부 색 농도, 반투명 중첩, 유리 가장자리 굴절, 하이라이트 형태를 SVG 벡터 요소로 다시 구성했습니다.
- **형식**: 모든 로고 SVG는 실제 `<path>`, `<linearGradient>`, `<radialGradient>`, `<clipPath>` 레이어입니다. PNG / JPG 이미지 임베딩이 없습니다.
- **레이어**: `element-P`, `element-i-dot`, `element-i-stem`, `element-t` 그룹을 각각 편집할 수 있습니다.
- **투명 배경**: 앱 아이콘을 제외하면 배경 없는 SVG. 심볼형의 둥근 사각형은 로고의 일부입니다.
- **기타 스타일**: 간결형, 모노크롬, 라인형은 디자인 목적상 단순한 스타일을 유지했습니다.
- **유의**: AI 생성된 고광택 레퍼런스 이미지의 광학적 조명/굴절을 벡터로 근사한 것으로 픽셀 단위 동일성은 없습니다.
